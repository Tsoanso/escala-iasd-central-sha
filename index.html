Cópia de segurança

Os dados ficam salvos na nuvem e aparecem para todos. Exporte um arquivo de vez em quando para guardar uma cópia. "Importar" envia para a nuvem os dados de um arquivo exportado (inclusive da versão antiga do app).

Dados da versão anterior

Este navegador tem dados salvos pela versão anterior do app (antes da nuvem). Você pode enviá-los para a nuvem: configurações, membros e escalas. Os usuários antigos não são levados — cadastre-os de novo na aba Usuários, com e-mail.

Avisos aos escalados

Clique em Enviar para abrir o WhatsApp com a mensagem pronta para a pessoa. A mensagem pede que, se ela não puder ir, avise o líder responsável pela função. Os telefones são cadastrados em Membros (escalados) e em Usuários (líderes).

Novo usuário

Administrador: acesso a tudo. Líder: acessa Escala (vendo só os campos pelos quais é responsável) e Visualizar / Enviar (escala completa).
